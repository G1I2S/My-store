# Mi Tienda Online

Una tienda online moderna y responsive con un sistema de carrito de compras interactivo.

## Vista Previa

Tienda de productos tecnológicos con:
- Laptop Gamer AMD
- Mouse Inalámbrico
- Teclado Mecánico

## Características

- Diseño moderno con gradientes y animaciones
- Sistema de carrito con control de cantidad (+/-)
- Cálculo automático de totales por producto
- Total general actualizado en tiempo real
- Diseño responsive para móviles y desktop
- Efectos hover en las tarjetas de productos

## Tecnologías

- HTML5
- CSS3 (Flexbox, Gradientes, Transiciones)
- JavaScript Vanilla

## Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/G1I2S/My-store.git
```

2. Abre `index.html` en tu navegador
